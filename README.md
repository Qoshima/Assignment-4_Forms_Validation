# Assignment-4_Forms_Validation

## Structure

| File | Description |
|------|-------------|
| `index.html` | Part 1 — native HTML5 validation (Task 0, Task 1) |
| `part2.html` | Part 2 — Bootstrap validation with JS (Task 2, Task 3) |
| `part3.html` | Part 3 — registration form, custom JS checks (Task 4) |
| `styles.css` | Shared layout & navbar |
| `part1.css` / `part2.css` / `part3.css` | Part-specific styles |

## How to Run

Open `index.html` in any modern browser. No build step required.

## CDN Dependencies

Bootstrap 5.3.3 is loaded from jsDelivr CDN (Parts 2 & 3). Internet connection required.

## Validation Features

- **Part 1** – `required`, `min/max-length`, `pattern`, `min/max`, `step`, `type=email`
- **Part 2** – Bootstrap `was-validated`, `novalidate`, custom submit handler
- **Part 3** – password-match check, `setCustomValidity()`, success banner

## Technologies
HTML, CSS, Bootstrap 5.3.3, Vanilla JavaScript
